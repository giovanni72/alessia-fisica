# Fisica in 7 Giorni — Semestre Filtro Medicina (MUR)

Percorso intensivo 80/20 basato sul **Syllabus ufficiale MUR di Fisica (6 CFU, 7 Unità Didattiche)** per Medicina e Chirurgia, Odontoiatria e Veterinaria.

## Come usarlo subito
1. **Versione interattiva (con quiz e timer 50 min):** apri `index.html` direttamente nel browser (funziona 100% offline).
2. **Versione stampabile / iPad:** apri i PDF già generati nella cartella `pdf/`.
3. **Formulario tascabile:** tieni sempre aperto o stampato `pdf/00-Formulario-Unico.pdf` mentre studi i Giorni 1–6.

## Struttura del percorso
- **Giorno 1:** UD 1 (Metodi, SI, conversioni, vettori) + UD 2A (Cinematica)
- **Giorno 2:** UD 2B (Dinamica, Lavoro, Energia, Potenza, Quantità di moto, Leve nel corpo umano)
- **Giorno 3:** UD 3 (Meccanica dei fluidi: Stevino, Pascal, Archimede, Laplace, Continuità, Bernoulli, Poiseuille)
- **Giorno 4:** UD 5 (Termodinamica: Calore, Passaggi di stato, Gas perfetti, 1° e 2° Principio, Entropia)
- **Giorno 5:** UD 6 (Elettricità e Magnetismo: Coulomb, Condensatori/Membrana, Ohm, Circuiti, Effetto Joule, Lorentz, Induzione)
- **Giorno 6:** UD 4 (Onde, Suono, dB, Doppler) + UD 7 (Spettro EM, Fotoni, Radioattività, Emivita, Diagnostica)
- **Giorno 7:** Simulazione d'esame completa (31 quesiti in 50 minuti, punteggio stile MUR +1 / −0,25)
